## 导读

Vim 的高效来自模式与动作的组合，而不是单纯依赖鼠标或菜单。为了让常用操作更容易查找，本文将原有指令资料按使用场景整理成一篇独立博客，适合初学者建立操作地图，也适合作为日常编辑时的桌面速查表。

# Vim 常用指令速查参考手册

Vim 的核心逻辑基于**模式切换**。绝大多数高效操作都在**普通模式**（Normal Mode）下完成，输入文本则需切换至**插入模式**（Insert Mode），执行保存、退出或复杂替换需进入**底线命令模式**（Command-line Mode）。默认按下 `Esc` 键即可返回普通模式。

---

## 一、 模式切换与基础进入

| 指令      | 功能描述                               |
| --------- | -------------------------------------- |
| **`i`**   | 在光标**当前**位置进入插入模式         |
| **`I`**   | 在当前**行首**（非空字符）进入插入模式 |
| **`a`**   | 在光标**后一位**进入插入模式           |
| **`A`**   | 在当前**行尾**进入插入模式             |
| **`o`**   | 在当前行**下方**新开一行并进入插入模式 |
| **`O`**   | 在当前行**上方**新开一行并进入插入模式 |
| **`Esc`** | 从任何模式退出，返回**普通模式**       |

---

## 二、 光标移动（普通模式）

### 1. 基础方向

| 指令                                  | 功能描述                             |
| ------------------------------------- | ------------------------------------ |
| **`h`** / **`j`** / **`k`** / **`l`** | 左 / 下 / 上 / 右移动                |
| **`w`** / **`W`**                     | 移动到下个单词的开头（大写忽略标点） |
| **`b`** / **`B`**                     | 移动到上个单词的开头（大写忽略标点） |
| **`e`** / **`E`**                     | 移动到当前或下个单词的结尾           |

### 2. 行内与翻页

| 指令                   | 功能描述                                     |
| ---------------------- | -------------------------------------------- |
| **`0`** (数字零)       | 移动到当前行**绝对行首**                     |
| **`^`**                | 移动到当前行**第一个非空字符**               |
| **`$`**                | 移动到当前行**行尾**                         |
| **`gg`**               | 跳转到文件**第一行**                         |
| **`G`**                | 跳转到文件**最后一行**                       |
| **`NG`** 或 **`Ngg`**  | 跳转到第 **`N`** 行（如 `50G` 跳转到第50行） |
| **`Ctrl` + `f` / `b**` | 向下翻页 (Forward) / 向上翻页 (Backward)     |
| **`Ctrl` + `d` / `u**` | 向下翻半页 (Down) / 向上翻半页 (Up)          |

---

## 三、 复制、剪切（删除）与粘贴（普通模式）

| 指令                | 功能描述                                               |
| ------------------- | ------------------------------------------------------ |
| **`x`**             | 删除（剪切）光标当前所在的单个字符                     |
| **`dd`**            | 删除（剪切）当前**整行**                               |
| **`ndd`**           | 删除（剪切）从当前行向下的 **`n`** 行                  |
| **`dw`**            | 删除（剪切）至当前单词结尾                             |
| **`d$`** 或 **`D`** | 删除（剪切）至当前行尾                                 |
| **`yy`**            | 复制当前**整行**                                       |
| **`nyy`**           | 复制从当前行向下的 **`n`** 行                          |
| **`yw`**            | 复制至当前单词结尾                                     |
| **`p`** (小写)      | 将剪切板内容粘贴到光标**之后**（若是整行则粘贴到下方） |
| **`P`** (大写)      | 将剪切板内容粘贴到光标**之前**（若是整行则粘贴到上方） |

---

## 四、 撤销与重做（普通模式）

| 指令             | 功能描述                      |
| ---------------- | ----------------------------- |
| **`u`**          | **撤销**上一步操作 (Undo)     |
| **`Ctrl` + `r**` | **重做**刚刚撤销的操作 (Redo) |
| **`.`**          | 重复上一次执行的普通模式命令  |

---

## 五、 查找与替换

### 1. 快速查找（普通模式）

| 指令           | 功能描述                         |
| -------------- | -------------------------------- |
| **`/pattern`** | 从光标处**向后**搜索 `pattern`   |
| **`?pattern`** | 从光标处**向前**搜索 `pattern`   |
| **`n`**        | 跳转到**下一个**搜索结果（同向） |
| **`N`**        | 跳转到**上一个**搜索结果（反向） |
| **`*`**        | 快速向下查找光标当前所在的单词   |
| **`#`**        | 快速向上查找光标当前所在的单词   |

### 2. 文本替换（底线命令模式 `:`）

| 指令                   | 功能描述                                             |
| ---------------------- | ---------------------------------------------------- |
| **`:s/old/new/`**      | 替换**当前行**的**第一个**匹配项                     |
| **`:s/old/new/g`**     | 替换**当前行**的**所有**匹配项 (g=global)            |
| **`:%s/old/new/g`**    | 替换**整个文件**中的**所有**匹配项                   |
| **`:%s/old/new/gc`**   | 替换整个文件，并在每次替换前**提示确认** (c=confirm) |
| **`10,20s/old/new/g`** | 在第 10 行到第 20 行之间进行全部替换                 |

## 六、 可视模式 (Visual Mode)

用于选中文本块，配合复制 (`y`)、剪切/删除 (`d`)、缩进 (`>` 或 `<`) 使用。

| 指令              | 功能描述                                                 |
| ----------------- | -------------------------------------------------------- |
| **`v`**           | 进入**字符级**可视模式（逐个字符选择）                   |
| **`V`**           | 进入**行级**可视模式（逐行选择）                         |
| **`Ctrl` + `v**`  | 进入**块级**可视模式（矩形选择，常用于批量注释或列操作） |
| **`>`** / **`<`** | 将选中的文本块向右 / 向左缩进                            |

---

## 七、 保存、退出与环境设置（底线命令模式 `:`）

在普通模式下输入 `:` 进入，执行后自动返回普通模式。

| 指令                            | 功能描述                                   |
| ------------------------------- | ------------------------------------------ |
| **`:w`**                        | **保存**当前文件 (Write)                   |
| **`:q`**                        | **退出** Vim (Quit)，若有未保存修改会警告  |
| **`:wq`** 或 **`:x`**           | **保存并退出**                             |
| **`:q!`**                       | **强制退出**，丢弃所有未保存的修改         |
| **`:w <filename>`**             | 另存为指定文件名                           |
| **`:set nu`** / **`:set nonu`** | 开启 / 关闭显示行号 (number)               |
| **`:set hlsearch`**             | 开启搜索结果高亮 (highlight search)        |
| **`:set paste`**                | 开启粘贴模式（防止外部粘贴代码时缩进错乱） |

---

## 八、 分屏与多文件操作

| 指令                                  | 功能描述                                     |
| ------------------------------------- | -------------------------------------------- |
| **`:sp <file>`**                      | 水平分割窗口 (Split) 并打开文件              |
| **`:vsp <file>`**                     | 垂直分割窗口 (Vertical Split) 并打开文件     |
| **`Ctrl` + `w`, `w**`                 | 在不同的分屏窗口之间循环切换焦点             |
| **`Ctrl` + `w`, 方向键**              | 按照方向（上下左右或 h j k l）切换到指定窗口 |
| **`:close`** 或 **`Ctrl` + `w`, `c**` | 关闭当前光标所在的分屏窗口                   |

## 小结

学习 Vim 可以从“进入插入模式、回到普通模式、移动、修改、保存退出”这条主线开始。熟悉基础动作后，再把查找替换、可视模式和分屏操作组合起来，效率会自然提升。
