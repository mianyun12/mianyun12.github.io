## 导读

进程管理是系统编程中连接程序控制流、操作系统资源和 Shell 行为的重要主题。本文把进程创建、等待、映像替换和 Shell 内置命令放在同一份速查文章中，便于对比它们各自的作用、参数和返回行为。

# Linux 进程管理函数速查手册

## 一、 进程创建、终止与同步

### 1. `fork()`

- **作用**: 创建一个新的进程（子进程），并将当前进程的处理器状态和地址空间直接拷贝到新进程中。Linux 采用写时复制 (`copy_on_write`) 技术，仅在数据被修改时才进行实际的内存复制，从而提高调用 `exec()` 族函数的效率。  
- **参数**: 无 (`void`)。  
- **返回值**: 在父进程中，返回新创建子进程的 PID。在子进程中，返回 `0`。  

### 2. `exit()`

- **作用**: 终止当前进程（子程序），通常在程序运行结束或需要主动结束时调用。  
- **参数**: `status`，表示进程退出时的结束状态值。该状态值会作为子进程的结束状态提供给 `wait()` 函数。  
- **返回值**: 无 (`void`)。  

### 3. `wait()`

- **作用**: 使父进程的状态变为等待，直到其所有子进程中的任何一个成功退出并返回结束状态值，父进程才继续运行。用于确保子进程在父进程之前完成或避免产生僵尸进程。如果调用时已有可用的结束状态值，函数会立即返回。  
- **参数**: `stat_loc`，用于储存等待进程结束状态值（exit code）的指针，也可以设为 `NULL`。  
- **返回值**: 成功时返回结束状态值对应的子进程 PID。失败（如没有可等待的子进程）时返回 `-1`。  

### 4. `waitpid()`

- **作用**: `wait()` 的变体，可以指定等待特定 PID 的进程，并提供更多控制选项。  
- **参数**:
  - `pid`: 指定等待规则（`>0` 等待特定 PID 子进程；`-1` 等待任何子进程；`0` 等待同进程组子进程；`<-1` 等待特定进程组进程）。  
  - `stat_loc`: 存储退出状态的指针。  
  - `options`: 特殊的控制选项，设为 `0` 时无特殊选项（此时若 `pid = -1` 则等同于 `wait()`）。  
- **返回值**: 成功时返回触发状态改变的子进程 PID。失败时返回 `-1`。  







## 二、 进程映像替换：系统调用 `execve`

### `execve()`

- **作用**: 最底层的 `exec` 系统调用，用于在当前运行的进程中执行新程序，销毁并替换当前进程的内存映像（代码段、数据段、堆和栈），但进程的 PID、PPID 等属性保持不变。  
- **参数**:
  - `pathname` / `filename`: 新程序的可执行文件绝对路径。  
  - `argv`: 命令行参数数组，第一个参数需与文件名一致，且必须以 `NULL` 结尾。  
  - `envp`: 环境变量数组（格式为“变量=数值”对），必须以 `NULL` 结尾。  
- **返回值**: 成功执行时不返回（新程序直接接管进程）。只有在执行失败时才会返回 `-1` 并设置 `errno`。  

## 三、 进程映像替换：`exec` 函数族变体

基于 `execve()` 封装的函数族，用于简化参数传递。函数名后缀字母代表了参数格式和功能差异：  

- **`l` (list)**: 参数以列表形式逐个传递。  
- **`v` (vector)**: 参数以字符串数组形式传递。  
- **`p` (path)**: 自动从 `PATH` 环境变量中查找可执行文件，无需绝对路径。  
- **`e` (environment)**: 允许通过数组显式传入自定义的环境变量。  

| **函数原型**                           | **参数格式**          | **寻址方式** | **环境变量**    | **返回值**                |
| -------------------------------------- | --------------------- | ------------ | --------------- | ------------------------- |
| **`execl`**`(path, arg, ...)`          | 列表 (以 `NULL` 结尾) | 需绝对路径   | 继承当前环境    | 成功不返回，失败返回 `-1` |
| **`execv`**`(path, argv[])`            | 数组 (以 `NULL` 结尾) | 需绝对路径   | 继承当前环境    | 成功不返回，失败返回 `-1` |
| **`execle`**`(path, arg, ..., envp[])` | 列表 (以 `NULL` 结尾) | 需绝对路径   | 自定义 (`envp`) | 成功不返回，失败返回 `-1` |
| **`execlp`**`(file, arg, ...)`         | 列表 (以 `NULL` 结尾) | `PATH` 查找  | 继承当前环境    | 成功不返回，失败返回 `-1` |
| **`execvp`**`(file, argv[])`           | 数组 (以 `NULL` 结尾) | `PATH` 查找  | 继承当前环境    | 成功不返回，失败返回 `-1` |
| **`execvpe`**`(file, argv[], envp[])`  | 数组 (以 `NULL` 结尾) | `PATH` 查找  | 自定义 (`envp`) | 成功不返回，失败返回 `-1` |

## 四、 Shell 内置 `exec` 命令

- **作用**: 属于 bash、zsh 等 shell 的内置概念，主要用于替换当前 shell 进程或修改 I/O 重定向行为。
- **参数与行为**:
  - **带命令参数** (`exec command [arguments...]`): shell 会调用系统调用替换自身进程为目标命令，命令执行完毕后直接退出（不返回原 shell）。
  - **不带命令参数，仅 I/O 重定向** (`exec [redirection...]`): shell 进程不被替换，仅修改当前 shell 的文件描述符（例如全局重定向 stdout/stderr）。
- **返回值**: 替换进程成功后无返回值且 shell 退出。纯重定向操作成功后继续执行当前 shell 后续指令。

## 小结

阅读进程相关接口时，建议同时关注“当前进程是否被替换”“父进程是否等待”“成功时是否返回”这几个关键问题。它们能够帮助你准确区分 `fork`、`wait` 和 `exec` 函数族的行为。
